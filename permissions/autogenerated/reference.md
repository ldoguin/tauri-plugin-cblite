## Default Permission

Default permission set — allows all plugin commands.

#### This default permission set includes the following:

- `allow-open-database`
- `allow-close-database`
- `allow-get-document`
- `allow-save-document`
- `allow-start-replication`
- `allow-stop-replication`
- `allow-execute-query`
- `allow-create-fts-index`
- `allow-list-indexes`
- `allow-save-blob`
- `allow-get-blob-data`
- `allow-write-export-file`
- `allow-register-listener`
- `allow-remove-listener`
